# Africa Adaptation Indicator Navigator

A public semantic search experience for climate-adaptation indicator definitions
in African policy contexts.

## Explore the collection

- Search with a plain-English policy question.
- Compare definitions across selected African and global policy frameworks.
- Filter by source scope, framework collection, and adaptation theme.
- Open the official source associated with each indicator.
