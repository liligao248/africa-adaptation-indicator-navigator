# Africa Adaptation Indicator Navigator

A public, Africa-focused semantic search tool for official climate-adaptation
indicator definitions. Search in English to discover related definitions across
selected policy frameworks and open the linked official source for each result.

This repository intentionally contains only the public website assets and the
source-linked indicator collection used by the browser search. It contains no
personal documents, credentials, private records, or server-side secrets.

The public site is available at:
https://liligao248.github.io/africa-adaptation-indicator-navigator/
